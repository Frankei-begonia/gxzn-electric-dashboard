# 广西智能制造职业技术学院电费量化状态屏

一个给宿舍屏幕使用的本地网页状态屏。它会把学校智慧能耗平台里的宿舍用电结算数据整理成余额、预计可用天数、每日趋势、回路明细和预警提醒。

学校系统通常每天约 12:00 结算并刷新昨天用电量，所以本项目默认每天 12:10 后采集一次。它显示的是学校已结算的历史用电数据，不是实时电表功率。

## 适合谁用

- 想在宿舍放一块屏幕长期显示余额和用电趋势。
- 不想每天打开微信服务号手动查余额。
- 不想改代码或手动编辑配置文件。
- 同校其他宿舍想复制一份，填自己的账号密码后直接使用。

## 最简单启动方式

先确认电脑已经安装 Node.js 18 或更高版本。没有安装时，去官网下载：

```text
https://nodejs.org/zh-cn/download
```

然后双击项目根目录里的任意一个启动文件：

```text
启动电费状态屏.bat
```

或：

```text
start-dashboard.bat
```

启动脚本会自动：

- 检查 Node.js 是否存在。
- 启动本地网页服务。
- 打开浏览器页面。
- 如果服务已经在运行，就直接打开页面。

启动后不要关闭黑色命令窗口，关闭后本地网页服务也会停止。

## 第一次配置

第一次打开网页后，进入配置页：

```text
http://localhost:8787/setup.html
```

在网页里填写：

- 学校名称
- 状态屏名称，例如宿舍号
- 宿舍用电账号
- 查询密码
- 每日采集时间
- 余额预警线
- 可用天数预警线

点“保存配置”，再点“采集一次”。采集成功后打开状态屏：

```text
http://localhost:8787
```

账号和密码只保存在本机 `config.local.json`，不会上传到 GitHub。

## 状态屏功能

- 当前余额：显示学校平台返回的账户余额。
- 预计可用：按近期日均消费估算还可用多少天。
- 最新结算日：显示最近一次学校已结算的用电度数和费用。
- 本月消费：显示本月消费金额和用电度数。
- 每日结算趋势：用柱状图显示每日用电，用折线显示费用。
- 回路明细：账号下有多个回路时自动汇总展示。
- 最近记录：快速查看最近几天结算数据。
- 预警提醒：余额过低、预计天数过低、用电异常偏高、数据可能未刷新时提示。

## 局域网屏幕访问

如果宿舍屏幕、平板或小主机和运行服务的电脑在同一个局域网，可以在屏幕设备上打开：

```text
http://运行服务电脑IP:8787
```

网页配置页里的“高级设置”可以选择是否允许局域网访问：

- `0.0.0.0`：允许同一局域网访问，适合宿舍状态屏。
- `127.0.0.1`：只允许本机访问，更保守。

如果局域网设备打不开，通常检查三点：

- Windows 防火墙是否允许 Node.js 访问网络。
- 屏幕设备和电脑是否在同一个 Wi-Fi 或局域网。
- 访问的是电脑局域网 IP，而不是 `localhost`。

会用命令行的同学也可以这样启动：

```bash
npm start
```

手动采集一次：

```bash
npm run refresh
```

## 网页配置保存在哪里

网页配置会保存到项目根目录：

```text
config.local.json
```

这个文件已经写进 `.gitignore`，不会被 Git 提交。

本地采集数据保存在：

```text
data/
```

这个目录也不会被提交。

公开仓库只应该包含 `config.example.json` 这样的示例配置，不应该包含真实账号、密码、宿舍地址、余额截图或采集数据。

## 配置字段说明

网页已经覆盖了常用配置。需要排查问题时，可以了解这些字段：

| 字段 | 说明 |
| --- | --- |
| `schoolName` | 页面顶部显示的学校名称。 |
| `loginUserCode` | 宿舍用电查询账号。 |
| `password` | 宿舍用电查询密码。 |
| `displayName` | 状态屏主标题，建议填宿舍名。 |
| `customerUserCode` | 可选。账号绑定多个用电户时，可指定其中一个客户编号。 |
| `port` | 本地网页端口，默认 `8787`。 |
| `bindHost` | 监听地址。`0.0.0.0` 允许局域网访问，`127.0.0.1` 只允许本机访问。 |
| `dailyRefreshTime` | 每天从几点后采集新数据，默认 `12:10`。 |
| `retryMinutes` | 采集失败后的重试冷却时间。 |
| `historyLimit` | 本地保留的历史采集快照数量。 |
| `alerts.lowBalance` | 余额低于多少元触发预警。 |
| `alerts.criticalDays` | 预计可用天数低于多少天触发预警。 |

## 常见问题

### 双击启动文件后提示没有 Node.js

安装 Node.js 18 或更高版本，然后重新双击启动文件。

官方地址：

```text
https://nodejs.org/zh-cn/download
```

### 页面显示“需要配置”

打开：

```text
http://localhost:8787/setup.html
```

填写账号和密码，保存后点“采集一次”。

### 采集失败

优先检查：

- 账号是否正确。
- 密码是否正确。
- 当前网络是否能访问学校平台。
- 学校智慧能耗平台是否临时不可用。

### 为什么不是实时电表读数

学校平台展示的是结算后的历史用电数据，通常每天约 12:00 刷新昨天数据。本项目不会推测实时功率，也不会把每日数据拆成不存在的时间段。

### 多个宿舍或多个账号怎么用

最简单的做法是复制多份项目目录，每份目录使用不同端口和不同网页配置。

如果一个账号绑定多个用电户，可以先不填“指定客户编号”。确实需要固定某一个用电户时，再从采集结果里找到对应编号填入。

## 项目结构

```text
.
├── 启动电费状态屏.bat      # 中文双击启动入口
├── start-dashboard.bat      # 英文双击启动入口
├── config.example.json      # 示例配置，公开仓库只放占位值
├── public/                  # 状态屏和配置页前端
├── scripts/                 # 启动脚本
├── src/
│   ├── energyClient.js      # 学校智慧能耗平台接口采集逻辑
│   ├── server.js            # 本地 HTTP 服务、配置 API 和定时采集
│   └── store.js             # 本地 JSON 缓存
└── data/                    # 本地采集结果，默认不提交
```
